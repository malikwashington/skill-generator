The artifact at the center

The profile

Everything turns on one artifact: a deep, living profile of who I am and what I've done. Every role is scored against it, every draft is tailored from it, every gap folds back into it. It is the single source of truth the whole system judges by — not a stage in the pipeline, but the substrate every stage runs on.

00

The trust spine

What makes LLM judgment safe to build on. These primitives run under every stage — the reason a fabricated claim or a poisoned job description can't reach a document or take an action.

skill-generator The governance that lets any of these be trusted: a hash-keyed review gate a skill can't ship without, plus fail-closed guards that hard-block send / submit / secret surfaces. Build a new skill or harden one you already have — same enforcement either way. Public
provenance gate JD-blind judges verify every synthesized claim entails from its source. A claim that traces to nothing is refused before it can reach a PDF. Private
confined judges Scoring, tailoring, and critique run as read-only subagents behind a data fence, so untrusted job text can never hijack an agent that can act. Private
validate + average Every judge response is schema-checked and rejected loud if off-contract; N independent runs are averaged and genuine disagreement is flagged, not smoothed away. Private
The threat model, honestly

These guards defend against untrusted external input — a poisoned job description can't hijack a judge or reach a document. They do not defend against me: grounding proves a claim traces to the profile, not that the profile is true. The system was never designed or tested to catch an operator who misrepresents themselves — that integrity is the operator's to hold, by design.

↻

Loops, not a line

The clean 01-07 sequence below is a simplification. Inside it, almost nothing runs once — stages iterate, and findings route backward to whatever stage owns them. That feedback is the design, not an afterthought; it's where most of the real engineering lives.

Every judgment is a loop. No judge is trusted once: each runs N times and averages, and a wide split re-judges rather than smoothing over. (Score, Decide)
Generate is a cycle, not a step. tailor → provenance → build — an unsupported claim or an under-filled page loops back to re-tailor and re-gate until it holds. compose loops inside that: measure the page, cut, measure again.
Findings route backward. The critique and blind-review gates don't just pass or fail — each finding is sent to the stage that owns it (the profile, the tailoring, or the build) and the package is rebuilt until it's clean.
The system feeds itself. Gaps and enrichment loop back into the profile; de-listing loops back into the records; the next cycle scores and tailors against a sharper profile than the last. The outer loop is the whole point.

02

Score

Judge true fit from evidence, not keywords — then cancel the model's run-to-run noise before trusting the number.

interpretive fitA four-dimension composite — must-haves, lane, seniority, nice-to-haves — reasoned from the whole profile, crediting transferable evidence.Private
3× run-averagingScore each role three times and average in code; a wide split is stamped a finding to re-judge, never averaged into false consensus.Private
comp + near-miss gatesHard comp floor with a graded near-miss band, so a role that misses on pay alone still surfaces for visibility instead of vanishing.Private
false-negative auditA monthly pass that scores everything the relevance gate dropped, catching a good role a hand-tuned regex would have silently filtered.Private
03

Ground

Grounding isn't one gate but a discipline applied wherever the system synthesizes: provenance holds each generated claim to entailment against its source; the coverage map holds the page to the terms it still needs to defend. Trust is layered, not a single checkpoint.

source entailmentIsolated judges see only the synthesized statement and its source lines — an informed judge rationalizes, an isolated one can only check entailment.Private
grounded coverage mapEvery skill and JD term cited to the exact bullet that homes it, or flagged uncited — so keep/drop decisions are grounded, never asserted.Private
04

Generate

Express the fit in the target's own language, then compose the strongest single page — the judge ranks by impact, the code measures the real page and fits it.

tailor-artifacts One personalized draft per target: proof points selected, the target's terms mirrored, anchor facts kept verbatim, a structural truth gate before review. Public
composeThe judge ranks every bullet and section by impact; the code measures the rendered page and cuts only as far as the overflow requires — never stranding a JD term that is truthfully defensible by demonstrated experience.Private
fill-to-pageAn automatic loop that pulls the highest-value unused evidence into an under-filled page — strongest page within one page, decided by the judge.Private
critique + blind screenAn informed critic gate and a cold blind reader who knows only the resume and the posting — two independent checks before Ready for Review.Private
05

Decide

Fit answers "is this a match?" This layer answers the question that orders the week: if I act now, what's the probability it works, and what single move most raises the odds?

lna Likelihood plus next-action: P(success | act now), the one highest-leverage step, and the odds after it — ranked by where effort moves the needle most. Public
interview likelihoodP(first-round interview | apply), judged distinct from fit — a perfect-fit role can be a long shot, a mediocre one a near-lock.Private

07

Learn — the loop closes

The pipeline is a loop, not a line. Demand the scorer can't credit surfaces as a gap and splits two ways — a skill I'd claim but haven't yet demonstrated in the profile (flesh the profile out until the claim is defensible), versus one I genuinely lack (a growth target). Either way the profile stays a superset of demonstrated experience, and each cycle compounds.

gaps loopEvery term the scorer can't yet credit surfaces with demand evidence into a growth tracker (the Profile Gaps sheet) — the market's own signal, turned into a to-do list.Private
claimed vs demonstratedThe distinction that drives the loop: a skill I'd claim but haven't shown gets written up with real evidence until it's defensible; a genuine gap becomes something to go build. The profile grows only on demonstrated truth, never assertion.Private

The three public windows

Each is a standalone, open-source repo you can clone and run — the same machinery, rebuilt minimally with the personal data stripped out. Together they show the pattern end to end: govern it, tailor with it, decide with it.

Stops at Ready for Review — never sends. maps to · 04 Generate lna ↗ A second-opinion decision layer: not "what's best" but where one action moves the needle most. Ranked by leverage, with reasoning attached. maps to · 05 Decide

Why only three are public. It's all mine to open-source — this isn't about permission. The full pipeline is a personal tool wired to my own data (profile, applications, decisions), and scrubbing that PII out of every corner isn't worth the hassle for something I run for myself. So what's public is a clean, standalone sample of the pattern; the rest stays private for practical reasons, not proprietary ones.

Every capability above shares one contract: code owns state and safety, a judge makes the call behind a validated schema, and a human decides before anything irreversible. Build one well and the next is the same kernel pointed somewhere new — which is how 25 of them came to exist.
